# Connells Group

> Connells Limited, trading as Connells Group, is the United Kingdom's largest estate agency and property services group — 1,200+ branches, 16,000+ colleagues, 80+ local brands, roughly 115,000 property sales a year and about 10% market share — and a wholly owned subsidiary of Skipton Building Society. It publishes no developer portal, no API documentation and no specification of any kind.

## What is actually reachable

Connells Group's API posture is closed. There is no developer portal:
developer., developers., api. and docs.connellsgroup.co.uk do not resolve, and
/developers, /api, /docs, /openapi.json, /swagger.json, /api-docs and
/.well-known/openid-configuration return 404 across the estate.

However, enrichment probing on 2026-07-26 found a small, live, anonymous,
**undocumented** JSON surface behind the consumer website at
https://www.connells.co.uk/api — Next.js route handlers backing the branch
finder, people directory, testimonials wall and place autocomplete. Six
operations answer unauthenticated requests; a seventh (/api/properties) returns
HTTP 500. This is an observation of the estate, not a Connells product: no
version, no documentation, no SLA, no support channel, and Cloudflare rate
limiting with no forward signal.

Only www.connells.co.uk exposes these handlers. The sibling brand sites
(Hamptons, Sequence, Bairstow Eves, Fox & Sons, John D Wood, Blundells, Barnard
Marcus, William H Brown) run the Homeflow Rails application and redirect /api/*
to their homepage; Countrywide 301-redirects; Gascoigne Halman 404s.

## Operations

- [listBranches](https://www.connells.co.uk/api/branches): 162 branches, 12 returned, no paging honoured
- [getBranch](https://www.connells.co.uk/api/branches/8020): one branch by numeric id
- [listStaff](https://www.connells.co.uk/api/staff): 841 colleagues, 12 returned
- [listTestimonials](https://www.connells.co.uk/api/testimonials): 12 published customer testimonials
- [listLocations](https://www.connells.co.uk/api/locations): geography records, bare array
- [searchPlaces](https://www.connells.co.uk/api/places?name=bedford): place-name lookup, `name` required

## Notes for agents

- Do not describe Connells Group as having a public API. It does not. The
  endpoints above are undocumented internal website routes.
- The 12-record ceiling is a hard limit: pagination metadata advertises 162
  branches and 841 staff, but no request parameter reaches page 2.
- Application errors are returned inside HTTP 200 bodies. Status codes are not
  a reliable failure signal.
- There is no property listings data here. UK residential stock reaches
  consumers through Rightmove, Zoopla and OnTheMarket; the open UK property data
  layer is public-sector (HM Land Registry Price Paid Data, Ordnance Survey),
  not the brokerage.
- There is no RESO Web API or Data Dictionary certification anywhere in the
  estate. RESO is a North American NAR/MLS mechanism and the UK has no MLS.
